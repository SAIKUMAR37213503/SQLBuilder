                  Databases

                    SQL Lab runs SQL in SQLite, a database engine embedded in this app. Your databases are kept on this device and nothing is sent anywhere. SQLite's SQL is close to standard SQL but not identical to SQL Server, PostgreSQL or MySQL, so SQL written for those may need changes here.
